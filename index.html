About the System

The Epilepsy Care System provides a platform for organising epilepsy-related information and supporting communication between patients, doctors and caregivers.

Patients can manage medication information, record health activities and request assistance. Doctors can review shared patient summaries and record consultation information.

Caregivers can respond to help requests and monitor medication dose status, while system administrators manage user accounts and monitor system activities.
